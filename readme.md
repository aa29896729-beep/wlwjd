# 텍스트 단어 빈도 시각화 및 감성 분석기

Streamlit과 Kiwi 형태소 분석기를 활용하여 텍스트 파일을 분석하고, 단어 빈도 시각화 및 감성 분석을 수행하는 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **사용자 사전 등록**: 분리되지 말아야 할 복합 명사나 고유 명사를 쉼표(`,`)로 구분해 등록
2. **텍스트 파일 업로드**: `.txt` 파일 업로드 및 내용 확인
3. **형태소 분석 및 전처리**: `kiwipiepy`를 활용한 2글자 이상 핵심 명사 추출
4. **단어 빈도 통계**: 상위 빈도 단어 수 슬라이더 조절 및 빈도표 표시
5. **시각화 (탭 인터페이스)**:
   - 가로 막대그래프
   - 워드클라우드 (한글 폰트 적용)
6. **감성 분석**:
   - 긍정·부정 감성 사전 기반 매칭 (동사·형용사는 기본형 `~다`로 복원하여 비교)
   - 긍정/부정 단어 목록 및 개수 확인
   - 원형 파이차트(Pie Chart) 비율 시각화

---

## 📁 디렉터리 구성

프로젝트 루트 디렉터리에 다음 파일들이 함께 위치해야 합니다.

```text
├── app.py               # 메인 Streamlit 파이썬 스크립트
├── requirements.txt     # 필요 패키지 목록
├── NanumGothic.ttf      # 한글 폰트 파일 (시각화용)
└── README.md            # 안내 문서
```

> **주의**: 한글 깨짐 방지를 위해 `NanumGothic.ttf` 폰트 파일이 스크립트 실행 경로에 반드시 필요합니다.

---

## 🚀 설치 및 실행 방법

### 1. 패키지 설치
터미널 또는 명령 프롬프트에서 `requirements.txt`에 명시된 의존 패키지들을 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
설치가 완료된 후 아래 명령어로 Streamlit 웹 앱을 구동합니다.

```bash
streamlit run app.py
```

브라우저가 자동으로 열리지 않는 경우, 터미널에 표시된 `http://localhost:8501` 주소로 접속하세요.

---

## 🛠 사용 방법

1. 상단 입력창에 분리를 방지할 사용자 단어(예: `인공지능, 워드클라우드`)를 입력합니다.
2. 분석할 `.txt` 파일을 업로드합니다.
3. 원본 텍스트 및 추출된 2글자 이상 명사 목록을 확인합니다.
4. 슬라이더를 조절하여 상위 단어 개수별 빈도표와 가로 막대그래프/워드클라우드를 확인합니다.
5. 최하단에서 텍스트의 긍정/부정 단어 검출 결과 및 비율 그래프를 확인합니다.
